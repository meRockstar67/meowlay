      Активные медиа (слои)

        Подключение...
        Фигуры: зажми мышь на холсте, тяни, отпусти. Текст: кликни, где написать. Медиа-объекты можно таскать мышкой, тянуть за синий квадратик — размер, кнопкой ⛶ — на весь экран. Shift+клик — выделить несколько объектов и таскать/удалять их вместе (Delete — удалить выделенное). Alt+перетаскивание по объекту — обрезка/сдвиг картинки внутри рамки, Alt+перетаскивание за уголок — приближение. Двойной клик по объекту сбрасывает обрезку. Ctrl+Z отменяет последнее действие — вообще любое (перемещение, удаление, поворот, папки и т.д.), не только рисунок. Текст можно увеличить, потянув за синий квадратик (растёт вместе с рамкой), либо ползунком "Размер" в списке активных медиа. В списке "Активные медиа" слева можно тянуть строки мышкой, чтобы менять, что поверх чего отображается (слои), а также перетаскивать их прямо на папку в разделе "Папки". Слева можно подключить предпросмотр Twitch-стрима — тогда вместо серого фона будет видно саму трансляцию, поверх которой ты рисуешь. Кнопка 👁 — скрыть/показать объект (не удаляя). Для загруженного видео: кнопка ▶ в списке всегда запускает видео сначала, "Зациклить" — крутить по кругу как гифку, есть отдельные ползунки громкости для OBS и для себя на сайте. Масштаб рабочей области: колесо мыши — приближение/ отдаление к курсору, кнопки ➖/➕/"Сбросить масштаб" — то же самое кнопками. Двигать область: зажми среднюю кнопку мыши, либо держи пробел и таскай левой кнопкой, либо выбери инструмент 🖐 "Двигать область" — тогда обычный клик и перетаскивание будут двигать саму зону, а не рисовать. На телефоне/планшете — сведи/разведи два пальца для масштаба, один палец с активным инструментом 🖐 — для сдвига.
