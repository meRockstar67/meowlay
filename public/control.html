Рабочая область — практически бесконечная. Кнопка "🖐 Режим панорамы" — самый надёжный способ подвигать вид: включил — тяни мышью где угодно (даже прямо по кадру), выключил — вернулось обычное рисование/перетаскивание медиа. Без включения режима панораму тоже можно подвинуть: зажать среднюю кнопку мыши (колесо) откуда угодно, либо обычную левую — по пустому тёмному фону вокруг кадра. Приближение/отдаление: кнопки ➖/➕, либо Ctrl + колесо мыши (или колесо в любом месте, когда включён "Режим панорамы") — обычное колесо без Ctrl теперь ничего не зумит, чтобы не мешать рисованию. Кадр — это то, что реально видно в OBS, всё за его пределами — черновая зона для подготовки. Если тащишь медиа-объект и уводишь курсор за край текущего вида — вид сам начнёт панорамироваться туда. Кнопка "Сбросить вид" возвращает исходный масштаб и кадр по центру.

Фигуры: зажми мышь на холсте, тяни, отпусти. Текст: кликни, где написать — поле появится прямо там же, печатай и жми Enter (Esc — отмена). Двойной клик по существующему тексту — редактировать его. Стрелки на клавиатуре — подвинуть выделенный объект на маленький шаг (Shift+стрелка — шаг покрупнее). Ctrl+D — продублировать выделенное. Медиа-объекты можно таскать мышкой, тянуть за синий квадратик — размер, кнопкой ⛶ — на весь экран. Shift+клик — выделить несколько объектов и таскать/удалять их вместе (Delete — удалить выделенное). Alt+перетаскивание по объекту — обрезка/сдвиг картинки внутри рамки, Alt+перетаскивание за уголок — приближение. Двойной клик по объекту сбрасывает обрезку. Ctrl+Z отменяет последнее действие — вообще любое (перемещение, удаление, поворот, папки и т.д.), не только рисунок. Текст можно увеличить, потянув за синий квадратик (растёт вместе с рамкой), либо ползунком "Размер" в списке активных медиа. В списке "Активные медиа" ниже можно тянуть строки мышкой, чтобы менять, что поверх чего отображается (слои), а также перетаскивать их прямо на папку в разделе "Папки". Вверху можно подключить предпросмотр Twitch-стрима — тогда вместо серого фона будет видно саму трансляцию, поверх которой ты рисуешь. Кнопка 👁 — скрыть/показать объект (не удаляя). Для загруженного видео: кнопка ▶ в списке всегда запускает видео сначала, "Зациклить" — крутить по кругу как гифку, есть отдельные ползунки громкости для OBS и для себя на сайте.
